# Contributions and reports

Submit only code and content you are entitled to contribute under the project's
GPL-compatible terms. Preserve third-party attribution and describe borrowed code
and its license. Do not submit subscriptions, tokens, real proxy nodes, runtime
configuration, unredacted logs or copyrighted payloads as fixtures.

Use synthetic fixtures such as example.com and documentation IP addresses.
Report suspected credential exposure privately through GitHub's private reporting
facility if available; never paste credentials into a public issue. Rotate exposed
credentials with their provider even if a repository copy is removed.

Respect each search service's access terms and applicable law. Do not add login,
paywall or CAPTCHA bypasses. Search results and links do not establish permission
to access or redistribute the underlying material.
